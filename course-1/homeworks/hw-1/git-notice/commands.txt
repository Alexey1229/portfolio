git init — создаёт новый репозиторий
git add — добавляет файлы в индекс
git status - проверяет статус репозитория (какие файлы изменены и готовность к сохранению)
git log - получвет логи (все коммиты, когда, кем, с каким сообщением)
git commit - создать коммит
git remote add - привязка к удалённому репозиторию
git branch - добавляет ветку
